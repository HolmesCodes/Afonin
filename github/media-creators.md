# 🎬 Для создания контента

> Инструменты для видео, дизайна, иконок и конвертации.

---

## 🎥 Видеоредакторы

| Проект | Описание |
|--------|----------|
| **[Kdenlive](https://github.com/KDE/kdenlive)** | Полноценный видеоредактор с таймлайном, дорожками, эффектами, цветокоррекцией и титрами. Работает на Windows, Linux и Mac. |

---

## 🎨 Иконки и дизайн

| Проект | Описание |
|--------|----------|
| **[Tabler Icons](https://github.com/tabler/tabler-icons)** | Набор из 6000+ бесплатных SVG-иконок с MIT-лицензией. Есть пакеты для React, Vue, Svelte и Angular. |

---

## 🖼️ Визуализация данных

| Проект | Описание |
|--------|----------|
| **[Viseron](https://github.com/roflcoopter/viseron)** | Self-hosted система видеонаблюдения с ИИ. Распознаёт людей, машины и движение на камерах. |
| **[DeepCamera](https://github.com/SharpAI/DeepCamera)** | Платформа для добавления AI-возможностей к камерам. Поддерживает YOLO, распознавание лиц и детекцию падений. |
