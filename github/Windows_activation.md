# Активация Microsoft Office и Windows (для справки)

## Microsoft Activation Scripts (MAS)

**Описание:** Открытый скрипт для активации Windows и Office. Работает на основе современных методов (HWID, Ohook, KMS38).

**Официальный сайт:** [massgrave.dev](https://massgrave.dev)

**Ссылка на GitHub:** [Microsoft-Activation-Scripts](https://github.com/massgravel/Microsoft-Activation-Scripts)

### Как использовать (в Windows)

Запусти PowerShell от имени администратора и выполни команду:
