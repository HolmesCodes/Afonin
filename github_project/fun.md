## 🎮 Инструменты

| Проект | Описание |
|--------|----------|
| **[LiveContainer](https://github.com/LiveContainer/LiveContainer)** | Лаунчер для iOS/iPadOS. Запускает IPA-приложения «внутри себя» без обычной установки. |
| **[Frida](https://github.com/frida/frida)** | Подключается к запущенному приложению и позволяет смотреть, что оно делает изнутри. Используется для реверс-инжиниринга на Android и iOS. |
