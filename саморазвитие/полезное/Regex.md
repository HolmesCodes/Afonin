# Шпаргалка по регулярным выражениям (Regex)

## 1. Якоря (Позиция в строке)

Они не ищут буквы, а указывают, *где* должен находиться паттерн.

| Символ | Название | Описание | Пример (шаблон → что найдет) |
| :--- | :--- | :--- | :--- |
| `^` | Начало строки | Строка должна начинаться с шаблона | `^Привет` → найдет `Привет` в начале строки, но не в середине |
| `$` | Конец строки | Строка должна заканчиваться шаблоном | `пока$` → найдет `пока` только в конце строки |
| `\b` | Граница слова | Начало или конец слова (между буквой и пробелом) | `\bcat\b` → найдет `cat` как отдельное слово, но не в `catalog` |
| `\B` | Не граница слова | Позиция внутри слова | `\Bcat\B` → найдет `cat` внутри `scatty` |

## 2. Классы символов (Что ищем)

| Символ | Описание | Пример |
| :--- | :--- | :--- |
| `[abc]` | **Один** любой из перечисленных: a, b или c | `[тл]ень` → найдет `тень` и `лень` |
| `[^abc]` | **Один** любой, **кроме** a, b, c | `[^л]ес` → найдет `лес`? Нет (исключили л), найдет `бес` |
| `[A-Z]` | Диапазон: любая заглавная буква | `[A-Z]` в `Виталий` → найдет `В` |
| `[a-z0-9]` | Любая маленькая буква или цифра | `[a-z]` в `123a` → найдет `a` |
| `.` | **Точка** — Любой символ (кроме перевода строки) | `л.с` → найдет `лес`, `лис`, `л0с`, `л с` |
| `\w` | **Word** — Любая буква, цифра или _ (аналог `[A-Za-z0-9_]`) | `\w+` → найдет все слова |
| `\W` | **Not Word** — Всё, кроме букв/цифр/_ | `\W` → найдет пробелы, запятые, точки |
| `\d` | **Digit** — Любая цифра (0-9) | `\d{3}` → найдет `123`, `456`, `000` |
| `\D` | **Not Digit** — Всё, кроме цифр | `\D+` → найдет все не-цифры в строке |
| `\s` | **Space** — Пробельный символ (пробел, табуляция, новая строка) | `\s` → найдет все пробелы |
| `\S` | **Not Space** — Не пробельный символ | `\S+` → найдет куски текста без пробелов |

## 3. Кванторы (Сколько раз повторяется)

| Символ | Название | Описание | Пример |
| :--- | :--- | :--- | :--- |
| `+` | Плюс | **1 и более** раз | `го+` → найдет `го`, `гоо`, `гооо` (но не `г`) |
| `*` | Звездочка | **0 и более** раз | `го*` → найдет `г`, `го`, `гоо` |
| `?` | Вопросительный знак | **0 или 1** раз (делает символ необязательным) | `цвет?` → найдет `цвет` и `цвет?` (в смысле, `цвет` без окончания тоже подходит) |
| `{3}` | Фигурные скобки | Точно **3** раза | `\d{3}` → найдет ровно 3 цифры подряд |
| `{2,5}` | Диапазон | От **2** до **5** раз | `a{2,5}` → `aa`, `aaa`, `aaaa` |
| `{3,}` | От и до | **3 и более** раз | `ba{3,}` → `baaa`, `baaaa` |

## 4. Группы и ссылки

| Символ | Описание | Пример |
| :--- | :--- | :--- |
| `(...)` | Группа (захватывающая). Сохраняет найденное | `(кот)` → найдет `кот`, запомнит его как `\1` |
| `\1`, `\2` | Обратная ссылка на группу | `(..)\1` → найдет `блибли` (любые два символа, повторенные дважды) |
| `(?:...)` | Группа без захвата (не запоминает) | Нужно для группировки внутри ` | `, но без сохранения в памяти |

**Пример с группой и ссылкой:**  
Ищем повторяющиеся слова: `\b(\w+)\s+\1\b`  
(Находит `word word`, где `\1` — это первая группа `(\w+)`).

## 5. Чередование (Логическое ИЛИ)

| Символ | Описание | Пример |
| :--- | :--- | :--- |
| `\|` | ИЛИ (альтернатива) | `кот\|пес` → найдет `кот` **или** `пес` |

`(понедельник\|вторник)` найдет любой из этих дней.

## 6. Флаги (Модификаторы после слеша)

В питоне/JS пишутся после `//`, например `/hello/gi`.

| Флаг | Название | Описание |
| :--- | :--- | :--- |
| `i` | Ignore case | Не чувствителен к регистру (`Hello` == `hEllO`) |
| `g` | Global | Ищет **все** совпадения в строке, а не останавливается на первом |
| `m` | Multiline | `^` и `$` работают для **каждой** строки, а не для всего текста целиком |

## 7. Просмотры (Lookahead / Lookbehind)

*Это продвинутая тема. Они проверяют условие, **не** включая его в результат поиска.*

| Символ | Название | Описание | Пример |
| :--- | :--- | :--- | :--- |
| `X(?=Y)` | Положительный просмотр вперед | Найти X, **только если** за ним идет Y | `вар(?=енье)` → найдет `вар` в `варенье`, но не в `вареник` |
| `X(?!Y)` | Отрицательный просмотр вперед | Найти X, **если** за ним **не** идет Y | `вар(?!енье)` → найдет `вар` в `вареник`, но не в `варенье` |
| `(?<=Y)X` | Положительный просмотр назад | Найти X, **если** перед ним есть Y | `(?<=машина )красная` → найдет `красная` только после слова `машина` |
| `(?<!Y)X` | Отрицательный просмотр назад | Найти X, **если** перед ним **нет** Y | `(?<!машина )красная` → найдет `красная`, если перед ним НЕТ слова `машина` |

## 🎯 Живой пример под звездочкой

**Задача:** Найти номер телефона `+7 (912) 345-67-89` в тексте и заменить на чистые цифры `79123456789`.

**Решение:**  

1. Шаблон для поиска: `\+7\s*\(?(\d{3})\)?[\s-]*(\d{3})[\s-]*(\d{2})[\s-]*(\d{2})`
2. Замена: `7$1$2$3$4`

*(+ экранируем, \s* пропускаем пробелы, \(? то скобка есть то нет, (\d{3}) захватываем блоки цифр, [\s-]*пропускаем пробелы/тире)*
