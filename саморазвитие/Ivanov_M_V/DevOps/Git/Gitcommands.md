# 📘 Полная шпаргалка по Git

> Все основные команды для повседневной работы.  
> Актуально для твоего репозитория `notes` и любых других проектов.

---

## 🔧 Настройка Git

| Команда | Что делает |
| --------- | ------------- |
| `git config --global user.name "Твое Имя"` | Устанавливает имя для всех коммитов |
| `git config --global user.email "email@example.com"` | Устанавливает email |
| `git config --global core.editor "code --wait"` | Устанавливает VS Code редактором по умолчанию |
| `git config --list` | Показывает все текущие настройки |

---

## 🆕 Создание и клонирование

| Команда | Что делает |
| --------- | ------------- |
| `git init` | Инициализирует новый Git-репозиторий в текущей папке |
| `git clone <url>` | Клонирует удалённый репозиторий на компьютер |
| `git clone <url> <имя-папки>` | Клонирует в указанную папку |

---

## 📁 Базовые команды

| Команда | Что делает |
| --------- | ------------- |
| `git status` | Показывает состояние репозитория (что изменено, что добавлено) |
| `git add <файл>` | Добавляет файл в индекс (подготовка к коммиту) |
| `git add .` | Добавляет **все** изменённые и новые файлы в текущей папке |
| `git add -A` | Добавляет **абсолютно все** изменения во всём репозитории |
| `git rm <файл>` | Удаляет файл из репозитория и с диска |
| `git rm --cached <файл>` | Удаляет файл из Git, но оставляет на диске (полезно для `.gitignore`) |
| `git mv <старое> <новое>` | Переименовывает файл/папку с отслеживанием в Git |

---

## 💾 Коммиты

| Команда | Что делает |
| --------- | ------------- |
| `git commit -m "сообщение"` | Создаёт коммит с сообщением |
| `git commit -am "сообщение"` | Добавляет **все отслеживаемые** файлы и создаёт коммит (пропускает `git add` для уже отслеживаемых) |
| `git commit --amend -m "новое сообщение"` | Изменяет последний коммит (сообщение или содержимое) |
| `git commit --amend --no-edit` | Добавляет текущие изменения в последний коммит без изменения сообщения |

## 🌿 Ветки (Branches)

| Команда | Что делает |
| --------- | ------------- |
| `git branch` | Показывает список локальных веток (`*` — текущая) |
| `git branch -r` | Показывает удалённые ветки |
| `git branch -a` | Показывает все ветки (локальные + удалённые) |
| `git branch <имя>` | Создаёт новую ветку |
| `git checkout <ветка>` | Переключается на другую ветку |
| `git switch <ветка>` | Тоже переключение (более новый способ) |
| `git checkout -b <ветка>` | Создаёт и сразу переключается на новую ветку |
| `git branch -d <ветка>` | Удаляет ветку (локально) |
| `git branch -D <ветка>` | Принудительно удаляет ветку (даже если не слита) |
| `git push origin --delete <ветка>` | Удаляет ветку на GitHub |

## 🔀 Слияние (Merge) и перебазирование (Rebase)

| Команда | Что делает |
| --------- | ------------- |
| `git merge <ветка>` | Вливает указанную ветку в текущую |
| `git merge --abort` | Отменяет слияние, если были конфликты |
| `git rebase <ветка>` | Перебазирует текущую ветку поверх указанной |
| `git rebase --continue` | Продолжает rebase после разрешения конфликтов |
| `git rebase --abort` | Отменяет rebase |

---

## 🌍 Работа с удалённым репозиторием (GitHub)

| Команда | Что делает |
| --------- | ------------- |
| `git remote -v` | Показывает список удалённых репозиториев |
| `git remote add origin <url>` | Добавляет удалённый репозиторий с именем `origin` |
| `git remote remove origin` | Удаляет привязку к удалённому репозиторию |
| `git push -u origin main` | Отправляет локальную ветку `main` на GitHub и устанавливает связь (`-u`) |
| `git push` | Отправляет изменения (если связь уже настроена) |
| `git pull` | Забирает изменения с GitHub и сливает с локальной веткой |
| `git pull --rebase` | Забирает изменения и перебазирует (чище история) |
| `git fetch` | Забирает изменения **без слияния** (просто скачивает) |
| `git clone <url>` | Клонирует репозиторий (уже было выше, но важно повторить) |

## 📜 Просмотр истории

| Команда | Что делает |
| --------- | ------------- |
| `git log` | Показывает полную историю коммитов |
| `git log --oneline` | Каждый коммит в одну строку (короткий хеш + сообщение) |
| `git log --graph --oneline --decorate --all` | **Красивый граф** всех веток (ASCII) |
| `git log -p` | Показывает изменения (diff) внутри каждого коммита |
| `git log --since="2 days ago"` | Коммиты за последние 2 дня |
| `git log --author="имя"` | Коммиты конкретного автора |
| `git show <хеш>` | Показывает информацию о конкретном коммите |
| `git diff` | Показывает неподтверждённые изменения (до `git add`) |
| `git diff --staged` | Показывает изменения, которые уже в индексе (после `git add`) |
| `git diff <ветка1>..<ветка2>` | Разница между двумя ветками |

## 🔄 Отмена изменений

| Команда | Что делает |
| --------- | ------------- |
| `git restore <файл>` | Отменяет **некоммиченные** изменения в файле |
| `git restore --staged <файл>` | Убирает файл из индекса (отмена `git add`) |
| `git reset HEAD~1` | Отменяет последний коммит, оставляя изменения в рабочей папке |
| `git reset --hard HEAD~1` | Полностью удаляет последний коммит **безвозвратно** |
| `git reset --hard <хеш>` | Возвращает репозиторий к состоянию указанного коммита (потеря изменений) |
| `git revert <хеш>` | Создаёт новый коммит, который отменяет указанный (безопасно, не теряет историю) |

## 🗑️ Работа с .gitignore

| Команда / Действие | Что делает |
| ------------------- | ------------- |
| Создать `.gitignore` | Текстовый файл со списком файлов/папок, которые Git будет игнорировать |
| `echo "secrets.md" >> .gitignore` | Добавляет `secrets.md` в игнор |
| `git rm --cached <файл>` | Останавливает отслеживание файла, уже попавшего в Git |
| `git check-ignore -v <файл>` | Проверяет, какой именно правило `.gitignore` игнорирует файл |

# Секреты
