## 📥 Как добавить новый материал

1. Выбери нужную папку или создай новую:
   ```bash
   mkdir -p ~/notes/саморазвитие/Новая_тема
   ```
2. Добавь файлы (конспекты, код, ссылки).
3. Добавь в Git:
    ```bash
    git add саморазвитие/Твоё ФИО/Добавить файл или папку
    git commit -m "feat(self-dev): добавил папку Новая_тема"
    git push git push -u origin твоя ветка
    ```
---
## Важный момент
Создай обязательно папку со своим ФИО на латинице!  
Все папки без ФИО считаются общими и в них добавлять изменения могут все, а в твою только ты.
Как это работает? 
1. Я увижу название ветки (шаблон по тому как ее оформить лежит **[здесь](шаблоны/attention/GuideForWork.md)**)
2. В названии ветки будет твое ФИО, я сравню его с твоим аккаунтом на [GitHub](https://github.com/Mikhail-69/notes/graphs/contributors)
3. Если все норм, я замерджу ветку, если нет - я напишу комментарий об этом и буду ждать фидбека
