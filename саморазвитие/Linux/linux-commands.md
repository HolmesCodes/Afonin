# 🐧 Linux — шпаргалка по командам (Ubuntu)

> Основные команды для работы в терминале.  
> Актуально для Ubuntu и большинства Debian-подобных дистрибутивов.

---

## 📂 Навигация по файловой системе

| Команда | Описание |
|---------|----------|
| `pwd` | Показать текущую директорию |
| `ls` | Список файлов и папок в текущей директории |
| `ls -la` | Все файлы (включая скрытые) с подробной информацией |
| `cd <путь>` | Перейти в указанную директорию |
| `cd ..` | Перейти на уровень выше |
| `cd ~` | Перейти в домашнюю директорию |
| `cd /` | Перейти в корень системы |
| `mkdir <имя>` | Создать новую папку |
| `mkdir -p <путь>` | Создать папку с вложенными (если их нет) |
| `rmdir <имя>` | Удалить **пустую** папку |
| `rm -rf <имя>` | Удалить папку **со всем содержимым** (ОСТОРОЖНО!) |

---

## 📄 Работа с файлами

| Команда | Описание |
|---------|----------|
| `touch <файл>` | Создать пустой файл |
| `cp <исходник> <назначение>` | Скопировать файл |
| `cp -r <папка> <назначение>` | Скопировать папку рекурсивно |
| `mv <исходник> <назначение>` | Переместить или переименовать файл/папку |
| `rm <файл>` | Удалить файл |
| `rm -rf <папка>` | Удалить папку со всем содержимым |
| `cat <файл>` | Показать содержимое файла |
| `less <файл>` | Показать содержимое файла постранично (выход — `q`) |
| `head <файл>` | Показать первые 10 строк файла |
| `tail <файл>` | Показать последние 10 строк файла |
| `tail -f <файл>` | Следить за изменениями в файле (логи) |
| `nano <файл>` | Открыть файл в редакторе nano |
| `vim <файл>` | Открыть файл в редакторе vim |

## 🔍 Поиск

| Команда | Описание |
|---------|----------|
| `find <путь> -name "<имя>"` | Найти файлы по имени |
| `find <путь> -type f` | Найти все файлы в папке |
| `find <путь> -type d` | Найти все папки |
| `grep "<текст>" <файл>` | Поиск текста внутри файла |
| `grep -r "<текст>" <папка>` | Рекурсивный поиск текста в папке |
| `grep -i "<текст>"` | Поиск без учёта регистра |
| `which <команда>` | Показать путь к исполняемому файлу команды |
| `whereis <команда>` | Показать все пути, связанные с командой |

---

## 🔧 Права доступа

| Команда | Описание |
|---------|----------|
| `chmod +x <файл>` | Сделать файл исполняемым |
| `chmod 755 <файл>` | Установить права `rwxr-xr-x` |
| `chmod 644 <файл>` | Установить права `rw-r--r--` |
| `chown <пользователь> <файл>` | Сменить владельца файла |
| `chown <пользователь>:<группа> <файл>` | Сменить владельца и группу |
| `sudo` | Выполнить команду с правами суперпользователя |
| `sudo -i` | Перейти в root-сессию |

## 📦 Управление пакетами (APT)

| Команда | Описание |
|---------|----------|
| `sudo apt update` | Обновить список пакетов |
| `sudo apt upgrade` | Обновить все установленные пакеты |
| `sudo apt install <пакет>` | Установить пакет |
| `sudo apt remove <пакет>` | Удалить пакет (конфиги остаются) |
| `sudo apt purge <пакет>` | Удалить пакет **со всеми конфигами** |
| `sudo apt autoremove` | Удалить ненужные зависимости |
| `apt search <запрос>` | Поиск пакета по ключевому слову |
| `apt list --installed` | Показать все установленные пакеты |

## 🧠 Процессы и система

| Команда | Описание |
|---------|----------|
| `ps aux` | Список всех запущенных процессов |
| `ps aux \| grep <имя>` | Найти процесс по имени |
| `top` | Мониторинг процессов в реальном времени |
| `htop` | То же, но красивее (установи: `sudo apt install htop`) |
| `kill <PID>` | Остановить процесс по ID |
| `kill -9 <PID>` | Принудительно остановить процесс |
| `systemctl start <сервис>` | Запустить сервис |
| `systemctl stop <сервис>` | Остановить сервис |
| `systemctl restart <сервис>` | Перезапустить сервис |
| `systemctl status <сервис>` | Проверить статус сервиса |
| `systemctl enable <сервис>` | Добавить сервис в автозагрузку |
| `systemctl disable <сервис>` | Убрать сервис из автозагрузки |
| `journalctl -u <сервис>` | Просмотр логов сервиса |

## 🌐 Сеть

| Команда | Описание |
|---------|----------|
| `ping <адрес>` | Проверить доступность хоста |
| `curl <url>` | Отправить HTTP-запрос |
| `wget <url>` | Скачать файл |
| `ifconfig` | Информация о сетевых интерфейсах (устаревает) |
| `ip a` | Информация о сетевых интерфейсах (новый способ) |
| `netstat -tulpn` | Открытые порты и слушающие сервисы |
| `ss -tulpn` | Аналог netstat, более современный |
| `ssh <пользователь>@<адрес>` | Подключиться к удалённому серверу по SSH |
| `scp <файл> <пользователь>@<адрес>:<путь>` | Копировать файл через SSH |
| `rsync -av <исходник> <назначение>` | Синхронизация файлов (эффективнее scp) |

## 💾 Диски и память

| Команда | Описание |
|---------|----------|
| `df -h` | Свободное место на дисках (в человекочитаемом виде) |
| `du -sh <папка>` | Размер папки |
| `du -h --max-depth=1` | Размер всех папок в текущей директории |
| `lsblk` | Список всех дисков и разделов |
| `fdisk -l` | Детальная информация о дисках |
| `mount` | Список примонтированных файловых систем |
| `umount <точка_монтирования>` | Отмонтировать |
| `free -h` | Использование оперативной памяти |
| `cat /proc/meminfo` | Детальная информация о памяти |
| `lscpu` | Информация о процессоре |

## 📋 Классические связки команд (пайпы и перенаправление)

| Пример | Описание |
|--------|----------|
| `команда1 \| команда2` | Передать вывод первой команды как ввод для второй |
| `команда > файл` | Перенаправить вывод в файл (перезапись) |
| `команда >> файл` | Перенаправить вывод в файл (добавление в конец) |
| `команда < файл` | Использовать файл как ввод |
| `grep "ошибка" file.log \| wc -l` | Посчитать количество строк с "ошибка" в логе |

## 🧪 Примеры для новичков

```bash
# Обновить систему
sudo apt update && sudo apt upgrade -y

# Найти все файлы .conf в папке /etc
find /etc -name "*.conf"

# Проверить, занят ли порт 8080
sudo lsof -i :8080

# Посмотреть последние 20 строк лога в реальном времени
tail -f /var/log/syslog

# Скачать и распаковать архив
wget https://example.com/archive.tar.gz
tar -xzvf archive.tar.gz

# Скопировать папку с одного сервера на другой
rsync -av /local/folder/ user@ip:/remote/folder/
