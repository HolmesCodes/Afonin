# 📚 Библиотека

> Моя личная коллекция книг по программированию, психологии, языка и не только.

---

## 📂 Структура

```bash
books/

├── README.md # Этот файл  
├── Программирование/ # Книги по IT и разработке  
│ ├── Linux/ # Linux, Bash, терминал  
│ ├── Python/ # Python и всё, что с ним связано  
│ ├── C++/ # C++, алгоритмы, ООП  
│ ├── Git/ # Git, GitHub, система контроля версий  
│ ├── Algorithms/ # Алгоритмы и структуры данных  
│ ├── Databases/ # Базы данных, SQL, PostgreSQL  
│ ├── Web/ # Веб-разработка (HTML, CSS, JavaScript, React)  
│ └── DevOps/ # Docker, CI/CD, Kubernetes  
├── Психология/ # Книги по психологии, мышлению, поведению  
├── Бизнес/ # Бизнес, управление, стартапы, маркетинг  
├── Саморазвитие/ # Личная эффективность, привычки, soft skills    
├── Иностранные_языки/ # Английский, немецкий и другие языки
└── Other/ # Всё, что не вошло в другие категории
```

---

## 📋 Как пользоваться

1. **Найти книгу** — выбери категорию и посмотри список.
2. **Создать ветку** — Создай свою ветку и в нее добавь книгу.
3. **Добавить книгу** — положи файл в нужную папку.
4. **Обновить репозиторий** — после добавления сделай `git add` и `git commit`.
5. **Пингани меня** — я увижу твои изменения сам, но если нужно замерджить в течении короткого времени - напиши мне.
