# 📁 Шаблоны и шпаргалки

> Центральное хранилище всех шаблонов, чек-листов и шпаргалок для повседневной работы.  
> Это место, куда я обращаюсь, когда нужно быстро вспомнить синтаксис, правила или подходы.

---

## 📂 Структура

```bash
шаблоны/
├── README.md # Этот файл
├── Оформление/ # Шаблоны для оформления документов, кода, коммитов
│ ├── Conversial Commits.md # Правила оформления коммитов (Conventional Commits)
│ └── Markdown.md # Полное руководство по Markdown
├── Git/ # Шпаргалки по системе контроля версий
│ └── Gitcommands.md # Все основные команды Git
├── Linux/ # Шпаргалки по Linux
│ └── linux-commands.md # Команды Linux (Ubuntu) с примерами
└── attention/ # В ней хранится файл - гайд по работе с моим репозиторием
```

## 📥 Как использовать

1. **Найти нужный шаблон** — выбери категорию и открой соответствующий файл.
2. **Скопировать** нужную часть в свой проект или конспект.
3. **Дополнить** — если чего-то не хватает, добавь в файл и обнови репозиторий.
